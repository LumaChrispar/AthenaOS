# SRV-020: Book Formatter

**Document ID:** SRV-020  
**Version:** 1.0  
**Status:** Locked  
**Layer:** Service Layer  
**Type:** Support

---

## Identity & Mission
The production assembly engine. Takes all `APPROVED` chapter prose and compiles them into the Golden Master manuscript file, then generates publication-ready EPUB, PDF, and DOCX outputs. All formatting follows `PUB-001` strictly.

## Responsibilities
- Assemble all `APPROVED` chapters in correct order into a single `manuscript.md` (the Golden Master).
- Apply typographical standards from `PUB-001`: smart quotes, em-dashes, scene break ornaments, indentation rules.
- Generate front matter (title page, copyright, ToC) and back matter (author's note).
- Compile to EPUB, PDF, and DOCX using deterministic scripts.
- Trigger EPUB validation against IDPF EpubCheck.

## Interface Contract

```json
{
  "service_id": "SRV-020",

  "outputs": [
    "manuscript.md (Golden Master)",
    "book.epub",

    "book.docx",

    "Halts pipeline if EPUB validation fails."
  ]
}
```

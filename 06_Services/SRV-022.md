# SRV-022: Readability Auditor

**Document ID:** SRV-022  
**Version:** 1.0  
**Status:** Locked  
**Layer:** Service Layer  
**Type:** Support

---

## Identity & Mission
A sub-QA specialist that evaluates the cognitive ease of the prose. Ensures the reader is never forced to re-read a sentence due to syntactic complexity, ambiguity, or excessive density. Feeds the Readability Score to SRV-010.

## Responsibilities
- Calculate the passive voice rate per chapter (threshold: ≤ 15%, per `config/quality.yaml` QAR-002).
- Measure sentence length variety — a chapter of identically-structured sentences is a failure.
- Flag passages of more than three consecutive sentences of the same structure.
- Flag paragraphs of more than 8 lines (pacing issue in fiction).
- Return a Readability Score from 0–10.

## Interface Contract

```json
{
  "service_id": "SRV-022",
  "capability": "Readability Analysis",
  "inputs": [
    "chapter.schema.json (prose_content from all scenes)",
    "config/quality.yaml (passive voice threshold)"
  ],
  "outputs": [
    "Readability Score (0-10)",
    "Readability Report (specific flagged passages)",
    "ReadabilityCheckComplete event"
  ],
  "dependencies": ["SRV-010 (dispatches this service)"],
  "failure_conditions": [
    "Error if prose_content is empty.",
    "Score automatically reduces by 2 if passive voice exceeds 15% (QAR-002)."
  ]
}
```

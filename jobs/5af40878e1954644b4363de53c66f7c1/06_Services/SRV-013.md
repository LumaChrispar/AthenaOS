# SRV-013: Dialogue Master

**Document ID:** SRV-013  
**Version:** 1.0  
**Status:** Locked  
**Layer:** Service Layer  
**Type:** Support

---

## Identity & Mission
The specialist for spoken language. Ensures every line of dialogue serves a dual purpose — advancing plot or revealing character — and that each character sounds distinctly different from every other.

## Responsibilities
- Review dialogue in drafted scenes for subtext, distinctiveness, and narrative purpose.
- Cross-reference each character's `psychology.schema.json > speech_style` for voice consistency.
- Flag any dialogue that is "on the nose" (characters saying exactly what they mean, with no subtext).
- Propose rewrites for flagged lines; does not silently edit.

## Interface Contract

```json
{
  "service_id": "SRV-013",
  "capability": "Dialogue Quality Review",
  "inputs": [
    "scene.schema.json (prose_content)",
    "character/psychology.schema.json (for each character in scene)"
  ],
  "outputs": [
    "Dialogue Audit Report (flagged lines + rewrite proposals)",
    "DialogueAuditComplete event"
  ],
  "dependencies": ["SRV-003", "SRV-005"],
  "failure_conditions": [
    "Flags any scene where two characters cannot be distinguished by dialogue alone."
  ]
}
```

# SRV-015: Timeline Manager

**Document ID:** SRV-015  
**Version:** 1.0  
**Status:** Locked  
**Layer:** Service Layer  
**Type:** Support

---

## Identity & Mission
The guardian of chronological integrity. Maintains the master timeline of in-universe events and ensures that no scene, chapter, or flashback violates the established temporal logic of the story.

## Responsibilities
- Maintain `story_bible.json > timeline[]` as an ordered array of `timeline_event.schema.json` objects.
- Validate all new events against the existing timeline for chronological consistency.
- Track character locations across time — a character cannot be in two places simultaneously.
- Flag any time-gap inconsistencies (e.g., a journey that takes two pages but should take two weeks).

## Interface Contract

```json
{
  "service_id": "SRV-015",
  "capability": "Timeline Management",
  "inputs": [
    "chapter.schema.json (continuity_notes[])",
    "story_bible.json (existing timeline[])",
    "message.schema.json (Command: UpdateTimeline | ValidateTimeline)"
  ],
  "outputs": [
    "story_bible.json (timeline[] updated)",
    "Timeline Conflict Report (if contradictions found)",
    "TimelineUpdated event"
  ],
  "dependencies": ["SRV-009 (all writes routed through Story Bible Manager)"],
  "failure_conditions": [
    "Raises TimelineConflict alert if a new event contradicts an existing one.",
    "Error if a character appears in two locations in the same in-universe timestamp."
  ]
}
```

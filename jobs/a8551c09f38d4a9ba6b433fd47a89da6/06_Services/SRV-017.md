# SRV-017: Research Director

**Document ID:** SRV-017  
**Version:** 1.0  
**Status:** Locked  
**Layer:** Service Layer  
**Type:** Support

---

## Identity & Mission
The orchestrator of all fact-finding operations. Identifies knowledge gaps in the outline and world build, summons the appropriate Contract Specialist researchers, and synthesizes their findings into actionable Domain knowledge for the Story and Literary services.

## Responsibilities
- Analyse the project outline and world rules for factual accuracy requirements.
- Issue `SummonSpecialist` commands to load Contract Researchers (e.g., SRV-018 Historical Researcher).
- Synthesize research outputs and add them to `07_Domains/`.
- Maintain a Research Gap Log — unresolved questions that could cause factual errors if not addressed.

## Interface Contract

```json
{
  "service_id": "SRV-017",
  "capability": "Research Orchestration",
  "inputs": [
    "outline.json",
    "story_bible.json (world rules to validate)",
    "message.schema.json (Command: InitiateResearch)"
  ],
  "outputs": [
    "07_Domains/ (updated knowledge files)",
    "Research Gap Log",
    "ResearchCompleted event"
  ],
  "dependencies": [
    "SRV-018 (Historical Researcher)",
    "config/plugins/ (active genre plugin for domain requirements)"
  ],
  "failure_conditions": [
    "Error if Research Gap Log is non-empty when ResearchCompleted is published.",
    "Error if a world rule in story_bible.json has no validated factual basis."
  ]
}
```

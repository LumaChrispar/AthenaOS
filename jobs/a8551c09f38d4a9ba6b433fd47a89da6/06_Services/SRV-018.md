# SRV-018: Historical Researcher

**Document ID:** SRV-018  
**Version:** 1.0  
**Status:** Locked  
**Layer:** Service Layer  
**Type:** Contract Specialist [C]

---

## Identity & Mission
A domain expert in historical fact. Activated when the project requires accurate period detail — social customs, technology, warfare, language, clothing, economics — for any historical setting or era. Prevents anachronisms and factual inaccuracies.

## Activation Conditions
Summoned by SRV-017 (Research Director) when `outline.json` or `story_bible.json` references a specific historical period.

## Responsibilities
- Research and document the specific period's relevant customs and facts.
- Add findings to `07_Domains/History/[era].md`.
- Flag any world rules or character behaviours in the Story Bible that contradict historical fact.
- Provide a list of "period-accurate constraints" that restrict SRV-005 prose generation.

## Interface Contract

```json
{
  "service_id": "SRV-018",
  "capability": "Historical Research",
  "inputs": [
    "outline.json (period references)",
    "message.schema.json (Command: ResearchHistoricalPeriod)"
  ],
  "outputs": [
    "07_Domains/History/[era].md (period knowledge file)",
    "Historical Constraint List",
    "HistoricalResearchComplete event"
  ],
  "dependencies": ["SRV-017"],
  "failure_conditions": [
    "Error if historical period is not specified in the command payload.",
    "Flags any world rule in story_bible.json that contradicts documented historical fact."
  ]
}
```

# SRV-024: Workflow Manager

**Document ID:** SRV-024  
**Version:** 1.0  
**Status:** Locked  
**Layer:** Orchestration Layer  
**Type:** Support

---

## Identity & Mission
The operational backbone of the pipeline. Manages the Event Bus lifecycle — routing events to the correct services, tracking pipeline state, and handling failure and escalation conditions. Reports pipeline health to SRV-001 (CEO).

## Responsibilities
- Monitor the Event Bus for published events and route them to subscribed services per `event_bus.md`.
- Enforce the State Machine rules from `states.md` — reject illegal state transitions.
- Track per-chapter revision counts against the `max_revision_loops` defined in `config/workflow.yaml`.
- Trigger escalation procedures when chapters exceed maximum revision attempts.
- Summon Contract Specialists on demand (the Summoning Protocol from `SRV-000`).

## Interface Contract

```json
{

  ],
  "outputs": [

    "EscalationRequired event (when max loops exceeded)",
    "PipelineStatusReport (on request from SRV-001)"
  ],
  "dependencies": [

    "10_Workflows/states.md"
  ],
  "failure_conditions": [
    "Raises SystemHalt event if an illegal state transition is attempted.",
    "Raises DeadLetterQueue event if a service fails to respond within timeout_seconds."
  ]
}
```

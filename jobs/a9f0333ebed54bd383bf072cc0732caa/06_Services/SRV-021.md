# SRV-021: Reserved (Intentionally Unassigned)

**Document ID:** SRV-021
**Status:** Reserved — not implemented

---

This slot is intentionally empty. It was skipped during the original `EMP-xxx` →
`SRV-xxx` renumbering and left unassigned rather than reused, to avoid silently
repurposing a slot that `ORG-003`'s taxonomy or an external reference might
already associate with a different role.

If you assign this slot to a new service, delete this file and replace it with
`06_Services/SRV-021-<role-name>.md` following the same structure as the other
canonical service files (`## Identity`, `## Core Philosophy`, ..., `## Interface
Contract` with a fenced ```json block — `service_loader.py` depends on that
exact section header to extract a usable schema).

Until then: **do not dispatch SRV-021.** `service_loader.load_service("SRV-021", ...)`
will find this file, but it has no Interface Contract and is not wired into
`orchestrator.py`.

# SRV-010: QA Director

**Document ID:** SRV-010  
**Version:** 1.0  
**Status:** Locked  
**Layer:** Service Layer  
**Type:** Permanent Core

---

## Identity & Mission
The orchestrator of all quality processes. Does not perform QA itself — it coordinates the QA pipeline (SOP-005), dispatching sub-QA services and aggregating their scores into a composite verdict. The final authority on pass/fail.

## Responsibilities
- Trigger SOP-005 automatically on every `DraftCompleted` event.
- Dispatch Consistency, Originality, Readability, Structural, and Continuity checks to specialist services.
- Aggregate weighted scores using `config/quality.yaml` thresholds.
- Publish `ChapterApproved` or `ChapterRejected` events with Defect Reports.
- Track revision loops per chapter and escalate when `max_revision_loops` is reached.

## Failure Modes
- **Score Inflation:** Approving chapters below threshold to reduce revision cycles. QA Director cannot negotiate thresholds.
- **Missing Defect Detail:** A rejection with vague feedback is invalid. Every rejected dimension must cite specific chapter content.

## Interface Contract

```json
    "ChapterRejected event (with Defect Report)",
    "EscalationRequired event (if max loops reached)"

  "dependencies": [
    "SRV-022 (Readability Auditor)",
    "SRV-023 (Originality Auditor)",
    "SRV-016 (Continuity Editor)",
    "config/quality.yaml",
    "config/workflow.yaml"
  ],
  "failure_conditions": [
    "Error if config/quality.yaml is not loaded.",
    "Error if any sub-QA service fails to return a score."
  ]
}
```

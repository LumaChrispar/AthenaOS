## Video direction

**Palette system** (from `frame.md`, code-editorial - never invented): `cream` is the document surface and base plane; `ink` is all type and every rule; `tile` / `tile-strong` are the memo field bands, the redaction bar fill and the field that frames a screenshot; `coral` is the single scarce voltage - the `CLASSIFIED` stamp, PASS marks, the count, and the redaction bar's leading edge only. Nothing else is colored.

**Motion grammar + shot model.** Long-tail `power3` easing throughout. The reveal model is **VO-paced**: at t=0 only what the voice names then is on screen; each further element arrives on its spoken cue. The signature move remains the **redaction wipe** - a solid `tile-strong` bar clears left-to-right with a thin coral leading edge - and it is deliberately the same gesture as the `wipe` seam. Two seam types only: `cut` and `wipe`, alternating so the memo never reads as one repeated template.

**Real product captures.** Frames 3 and 9 place the ACTUAL captured interface (`public/athena-studio.png`, `public/athena-settings.png`) in a `tile` field with a hairline border and a mono path caption. These are real screenshots, not reconstructions - they are the credibility anchor of the whole film. Never redraw or stylise them; frame them, caption them, and let the coral ticks point.

**Framings - never the same twice in a row:** full-width strip (F1, F2, F12) · centered (F5, F13, F14) · screenshot-in-field, rule-of-thirds (F3, F9) · rule-of-thirds with right rail (F4, F6, F11) · mirrored strip (F7, F8) · split comparison (F10).

**Type.** `kicker` / `mono-label` for memo field labels (uppercase, tracked), `headline` / `display-italic` for hero values, `code` for service numbers, commands, file paths and status marks.

**Caption band.** All content is planned into the top ~83%; a centered hero anchors at y ~ 0.42 x height.

**Negative list.** No icons. No illustration standing in for a metaphor. No purple-blue "AI" gradients, no glowing orbs, no bokeh. No fabricated UI - where a real screenshot exists it is used; where one does not, the memo field carries type only, never a fake interface. Never slideshow (front-load then freeze) and never screensaver: reveals are cued to the spoken line and a resolved frame holds still.
